# 月明かりの窓辺

台紙1枚・素材8種類の静的ステッカーブック。`index.html`、`style.css`、`app.js` と `assets/` だけで動きます。元画像は変更せずコピーしています。

素材をタップして追加 → 台紙上で選んでドラッグ。選択中は矢印と下部の素材帯を隠し、選んだ素材の上に小さな「削除」だけを表示します。選択解除は空いた台紙のタップで行います。削除ボタンは画面端でも画面内に収まる位置に調整します。同じ素材は複数追加できます。フォルダーで保存した配置は、次回アクセス・再読み込み時に自動復元します。保存していない変更は残りません。

台紙はSafariの表示領域いっぱいに広がります。画像の縦横比を保って画面を埋めるため、画面比率に応じて端をトリミングします。下部の素材一覧は半透明の帯に重ねます。素材には四角い枠やチェック模様を付けず、帯に直接並べます。

初期表示は左上に「←」、下部に素材帯を表示します。矢印は表示だけでリンクはありません。空いた台紙をタップすると、矢印・素材帯・選択枠を全部隠して鑑賞できます。鑑賞中は、空いた台紙をタップすると素材一覧へ戻り、ステッカーをタップするとその素材を直接選択します。上部タイトル、「作品を見る」、下部の案内文は削除しました。

矢印の隣のカメラから、今見えている台紙の範囲とステッカーをPNG画像にして保存・共有できます。操作アイコン・素材帯・選択枠は画像に入りません。画像は表示領域と同じ比率、最大2倍（長辺2048pxまで）で生成します。ファイル共有に対応する環境では、カメラ → 端末の共有メニュー →「画像を保存」の流れです。未対応・共有エラー時は作品画像を表示し、画像の長押しまたはダウンロードから保存できます。キャンセル時は配置を維持します。配置の保存はカメラの隣のフォルダーで行います。

共有はユーザー操作が必要なため、カメラのクリック内で画像とFileを同期生成してからnavigator.shareを呼びます。PNGの対応をnavigator.canShareで確認し、写真への保存完了をアプリ側で断定しません。

ドラッグ中は素材の選択枠と削除ボタンを隠します。指を離した後も隠したままにし、配置した素材を1回タップすると枠と削除ボタンを再表示します。矢印は表示しません。選択中に空白をタップすると、素材一覧を挟まず直接作品だけの表示へ移ります。空白に指が触れた段階では選択を保持し、指を離した時点で切り替えるため、一覧のちらつきを防ぎます。

## iPhone Safariでの確認

- Safariの上下バーを表示したまま、台紙が表示領域いっぱいに広がり、下部操作が収まること。
- 素材一覧を左右にスワイプして、素材が誤追加されないこと。
- 月・ランプなどを複数貼り、指で移動できること。台紙の端で移動が止まること。
- 重ねた素材の見えている部分をタップして選択できること。
- 削除、空いた台紙のタップによる選択解除が動くこと。
- 空いた台紙をタップすると選択が解除され、矢印・素材帯・選択枠がすべて消えること。
- 鑑賞中にステッカーを1回タップすると、その素材の操作が直接表示されること。
- ドラッグ中と指を離した直後は枠・操作ボタンが消え、素材を1回タップすると戻ること。
- カメラ → 共有メニュー →「画像を保存」で写真アプリへ保存できること。保存画像の範囲・ステッカーの位置と重なり順が画面と一致し、操作表示が写っていないこと。
- 共有をキャンセルしても配置が残ること。共有非対応時の画像表示から長押し保存できること。

パソコンでの検証は実際のiPhone Safariでの確認を代替しません。

## 配置の手動保存

文字なしのフォルダーアイコンを押すと、この端末・ブラウザーに1作品の配置を保存し、保存しましたと短く表示します。ステッカーの種類・正規化した位置・配列順（重なり順）をlocalStorageのmoonlit-sticker-book.layout.v1へ記録します。自動保存は行いません。起動時は画像読み込み完了後に保存データを検証し、選択なしで復元します。Safariのサイトデータ削除や別の端末への引継ぎには対応していません。取り消しはver.2で追加予定です。

Chromeで、手動保存、複数・同種素材の位置と重なり順の復元、未保存変更の破棄、保存の上書き、空の作品、破損データを変更しないこと、容量エラー時の失敗表示を確認しました。iPhoneではフォルダーで保存後に再読み込みし、配置が戻ることを確認してください。

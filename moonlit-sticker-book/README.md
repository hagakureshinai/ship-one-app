# 月明かりの窓辺

台紙1枚・素材8種類の静的ステッカーブック。`index.html`、`style.css`、`app.js` と `assets/` だけで動きます。元画像は変更せずコピーしています。

素材をタップして追加 → 台紙上で選んでドラッグ。選択中は矢印と下部の素材帯を隠し、選んだ素材の上に小さな「削除」だけを表示します。選択解除は空いた台紙のタップで行います。削除ボタンは画面端でも画面内に収まる位置に調整します。同じ素材は複数追加できます。再読み込みすると配置は消えます。

台紙はSafariの表示領域いっぱいに広がります。画像の縦横比を保って画面を埋めるため、画面比率に応じて端をトリミングします。下部の素材一覧は半透明の帯に重ねます。素材には四角い枠やチェック模様を付けず、帯に直接並べます。

初期表示は左上に「←」、下部に素材帯を表示します。矢印は表示だけでリンクはありません。空いた台紙をタップすると、矢印・素材帯・選択枠を全部隠して鑑賞できます。鑑賞中は、空いた台紙をタップすると素材一覧へ戻り、ステッカーをタップするとその素材を直接選択します。上部タイトル、「作品を見る」、下部の案内文は削除しました。

ドラッグ中は素材の選択枠と削除ボタンを隠します。指を離した後も隠したままにし、配置した素材を1回タップすると枠と削除ボタンを再表示します。矢印は表示しません。選択中に空白をタップすると、素材一覧を挟まず直接作品だけの表示へ移ります。空白に指が触れた段階では選択を保持し、指を離した時点で切り替えるため、一覧のちらつきを防ぎます。

## iPhone Safariでの確認

- Safariの上下バーを表示したまま、台紙が表示領域いっぱいに広がり、下部操作が収まること。
- 素材一覧を左右にスワイプして、素材が誤追加されないこと。
- 月・ランプなどを複数貼り、指で移動できること。台紙の端で移動が止まること。
- 重ねた素材の見えている部分をタップして選択できること。
- 削除、空いた台紙のタップによる選択解除が動くこと。
- 空いた台紙をタップすると選択が解除され、矢印・素材帯・選択枠がすべて消えること。
- 鑑賞中にステッカーを1回タップすると、その素材の操作が直接表示されること。
- ドラッグ中と指を離した直後は枠・操作ボタンが消え、素材を1回タップすると戻ること。

パソコンでの検証は実際のiPhone Safariでの確認を代替しません。

# 月明かりの窓辺

台紙1枚・素材8種類の静的ステッカーブック。`index.html`、`style.css`、`app.js` と `assets/` だけで動きます。元画像は変更せずコピーしています。

素材をタップして追加 → 台紙上で選んでドラッグ。選択中は削除・選択解除が表示されます。同じ素材は複数追加できます。再読み込みすると配置は消えます。

台紙はSafariの表示領域いっぱいに広がります。画像の縦横比を保って画面を埋めるため、画面比率に応じて端をトリミングします。下部の素材一覧と操作メニューは半透明の帯に重ねます。素材には四角い枠やチェック模様を付けず、帯に直接並べます。

初期表示は左上に「←」、下部に素材帯を表示します。矢印は表示だけでリンクはありません。空いた台紙をタップすると、矢印・素材帯・選択枠を全部隠して鑑賞できます。鑑賞中はステッカーが動かず、画面のどこかをタップすると編集に戻ります。そのタップではステッカーを選択しません。上部タイトル、「作品を見る」、下部の案内文は削除しました。

## iPhone Safariでの確認

- Safariの上下バーを表示したまま、台紙が表示領域いっぱいに広がり、下部操作が収まること。
- 素材一覧を左右にスワイプして、素材が誤追加されないこと。
- 月・ランプなどを複数貼り、指で移動できること。台紙の端で移動が止まること。
- 重ねた素材の見えている部分をタップして選択できること。
- 削除、選択解除、空いた台紙のタップが動くこと。
- 空いた台紙をタップすると選択が解除され、矢印・素材帯・選択枠がすべて消えること。
- 鑑賞中にステッカーを触っても配置が動かず、タップすると編集に戻れること。

パソコンでの検証は実際のiPhone Safariでの確認を代替しません。

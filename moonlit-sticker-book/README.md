# 月明かりの窓辺

台紙1枚・素材8種類の静的ステッカーブック。`index.html`、`style.css`、`app.js` と `assets/` だけで動きます。元画像は変更せずコピーしています。

素材をタップして追加 → 台紙上で選んでドラッグ。選択中は削除・選択解除が表示されます。「作品を見る」で操作を隠し、台紙をタップすると編集に戻ります。同じ素材は複数追加できます。再読み込みすると配置は消えます。

GitHub Pages の公開ルートをリポジトリ直下に設定した場合のURL：
https://hagakureshinai.github.io/ship-one-app/moonlit-sticker-book/

## iPhone Safariでの確認

- Safariの上下バーを表示したまま、台紙全体と下部操作が収まること。
- 素材一覧を左右にスワイプして、素材が誤追加されないこと。
- 月・ランプなどを複数貼り、指で移動できること。台紙の端で移動が止まること。
- 重ねた素材の見えている部分をタップして選択できること。
- 削除、選択解除、空いた台紙のタップが動くこと。
- 「作品を見る」で操作と枠が消え、スクリーンショットを撮れること。台紙をタップすると戻れること。

パソコンでの検証は実際のiPhone Safariでの確認を代替しません。

# 月明かりの窓辺

台紙1枚・素材8種類の静的ステッカーブック。`index.html`、`style.css`、`app.js` と `assets/` だけで動きます。元画像は変更せずコピーしています。

素材をタップして追加 → 台紙上で選んでドラッグ。選択中は削除・選択解除が表示されます。同じ素材は複数追加できます。再読み込みすると配置は消えます。

台紙はSafariの表示領域いっぱいに広がります。画像の縦横比を保って画面を埋めるため、画面比率に応じて端をトリミングします。下部の素材一覧と操作メニューは半透明の帯に重ねます。上部タイトルは初期状態では非表示で、空いた台紙をタップすると表示・非表示を切り替えます。素材を追加・選択するとタイトルを隠します。「作品を見る」と下部の案内文は削除しました。

GitHub Pages の公開ルートをリポジトリ直下に設定した場合のURL：
https://hagakureshinai.github.io/ship-one-app/moonlit-sticker-book/

## iPhone Safariでの確認

- Safariの上下バーを表示したまま、台紙が表示領域いっぱいに広がり、下部操作が収まること。
- 素材一覧を左右にスワイプして、素材が誤追加されないこと。
- 月・ランプなどを複数貼り、指で移動できること。台紙の端で移動が止まること。
- 重ねた素材の見えている部分をタップして選択できること。
- 削除、選択解除、空いた台紙のタップが動くこと。
- 空いた台紙をタップすると選択が解除され、上部の半透明タイルにタイトルが表示されること。もう一度タップするとタイトルが消えること。

パソコンでの検証は実際のiPhone Safariでの確認を代替しません。
